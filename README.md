# 🧮 Simple Calculator

一个简洁而功能完整的网页计算器，使用纯 HTML、CSS 和 JavaScript 构建。

## ✨ 功能特性

- ➕ 基础四则运算（加、减、乘、除）
- 🎯 实时计算结果显示
- ⌨️ 支持键盘输入
- 🧹 清除和删除功能
- 🎨 现代化的UI设计，带有渐变背景
- 📱 完全响应式设计，支持移动设备
- ⚡ 平滑的动画和交互效果
- 🛡️ 错误处理机制

## 🚀 快速开始

### 方式一：直接打开
1. 克隆或下载此仓库
2. 在浏览器中打开 `index.html` 文件
3. 开始使用计算器！

### 方式二：使用本地服务器
```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Python 2
python -m SimpleHTTPServer 8000

# 使用 Node.js (http-server)
npx http-server
```
然后访问 `http://localhost:8000`

## ⌨️ 使用方法

### 鼠标操作
- 点击数字按钮输入数字
- 点击操作符按钮（+、-、×、÷）
- 点击 = 按钮计算结果
- 点击 C 清空所有内容
- 点击 DEL 删除最后一个字符

### 键盘操作
| 按键 | 功能 |
|------|------|
| `0-9` | 输入数字 |
| `+`, `-`, `*`, `/` | 输入操作符 |
| `.` | 输入小数点 |
| `Enter` 或 `=` | 计算结果 |
| `Backspace` | 删除最后一个字符 |
| `Escape` | 清空所有内容 |

## 🎨 设计特点

- **色彩方案**：紫色渐变背景，白色计算器卡片
- **按钮样式**：
  - 普通按钮：浅灰色
  - 清除按钮（C）：红色
  - 等号按钮（=）：蓝色
- **交互反馈**：悬停放大，点击收缩动画

## 🔧 技术栈

- **HTML5**：页面结构
- **CSS3**：样式和动画
- **Vanilla JavaScript**：交互逻辑

## 💡 示例

```
5 + 3 = 8
10 * 2.5 = 25
100 / 4 = 25
999 - 1 = 998
```

## 📝 注意事项

- 小数位数会自动舍入以避免精度问题
- 如果输入无效表达式，会显示 "Error" 提示
- 支持连续运算（如 5 + 3 - 2 = 6）
